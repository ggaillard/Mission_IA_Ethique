## 📖 Le scénario

> *Mardi 4 février 2025, 08h15.*
>
> Un post LinkedIn explose : une ingénieure avec 10 ans d'expérience accuse **TalentFlow** de l'avoir rejetée en 3,2 secondes. La CNIL ouvre une enquête.
>
> **Vous êtes développeur·se.** Vous avez accès au code. Vous voyez ce que le management ne voit pas.
>
> *Que faites-vous ?*

---

## 🎯 Objectifs pédagogiques

| Compétence | Description |
|------------|-------------|
| 🔍 **Analyser** | Identifier les biais dans les données et le code |
| ⚖️ **Évaluer** | Appliquer les 5 dimensions éthiques de l'IA |
| 📢 **Décider** | Choisir entre silence, alerte ou démission |
| 🛡️ **Protéger** | Implémenter des garde-fous (SHAP, Fairlearn) |
| 📜 **S'engager** | Construire sa charte éthique de développeur |

---

## 🚀 Les 7 phases de la mission

```
📱 ALERTE          Un post viral accuse l'IA de discrimination
     ↓
🔍 INVESTIGATION   Analyse des données, du code, des logs
     ↓
⭐ 5 DIMENSIONS    Légalité • Transparence • Équité • Autonomie • Soutenabilité
     ↓
⚡ DÉCISION        Corriger en silence ? Alerter ? Partir ?
     ↓
💻 GARDE-FOUS      Quick fix vs Refonte éthique
     ↓
📜 CHARTE          Construire ses principes
     ↓
🎓 RÉVÉLATION      Et après... ?
```
